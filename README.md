Скрипт `rename_for_plex.py` (и готовый `rename_for_plex.exe` для Windows) приводит имена
видеофайлов к формату, понятному Plex:

```
Сериал (Год) - sXXeYY - Название эпизода.ext
```

Он находит маркер серии (`S01E01`, `s01ep01`, `1x01`, `Season 1 Episode 2`) в любом мусоре,
вырезает релизные теги (`1080p`, `WEB-DL`, `x264`, `RUS`, `LostFilm` …), убирает дублирование
названия сериала и переименовывает файлы — с предварительным просмотром и резервной копией.

```
Roadhouse.Blues.S01E01.Pilot.1080p.WEB-DL.x264-GROUP.mkv
   ↓
Roadhouse Blues - s01e01 - Pilot.mkv
```

> **О названиях.** Репозиторий называется `rename-files-for-plex` (через дефисы — так принято на GitHub),
> а сам скрипт — `rename_for_plex.py`: в Python имя модуля не может содержать дефис, иначе его нельзя
> импортировать (это делают тесты). .exe собирается с тем же именем: `rename_for_plex.exe`.

## Зачем это нужно

Plex (и большинство медиасерверов) не умеют надёжно разбирать имена вида
`Show.Name.S01E01.1080p.WEB-DL.x264-GROUP.mkv` в папке с десятком сезонов.
Проще один раз привести имена к единому виду, чем каждый раз поправлять «неопознанные» серии вручную.

Скрипт работает офлайн, без интернета и без сторонних библиотек: только стандартная библиотека Python.

## Возможности

- 🖥️ **Один .exe для Windows** — не требует установленного Python; собирается из исходников одной командой.
- 🔍 **Маркер серии в любом окружении** — `S01E01`, `s01.e01`, `s01ep01`, `1x01`, `Season 1 Episode 2`.
- 🧹 **Очистка мусора** — разрешения, кодеки, звук, релиз-группы, площадки, языки и популярные русские озвучки.
- 📅 **Год выпуска** сохраняется как `(2019)`, чтобы Plex не путал ремейки.
- 🔤 **CamelCase и аббревиатуры** — `RoadhouseBlues` → `Roadhouse Blues`, `S.H.I.E.L.D` → `SHIELD`.
- 🚫 **Без дублей** — `Dexter.S01E01.Dexter.Pilot` → `Dexter - s01e01 - Pilot`.
- 📁 **Название сериала из папки** — файл `s01e01.mkv` внутри папки `Show Name` тоже будет переименован.
- 👀 **Режим просмотра** (`--dry-run`) — показывает план и ничего не меняет.
- 💾 **Резервная копия** — оригиналы складываются в `_backup_<дата>` с сохранением структуры папок.
- 🛡️ **Защита от конфликтов** — занятое имя получает суффикс `(1)`, `(2)`; регистр символов конфликтом не считается.
- 🪟 **Windows-безопасность** — удаляются символы `: ? * | < > " / \`, обрабатываются зарезервированные имена (`CON`, `COM1`), длинные имена обрезаются.
- 🧪 **CLI и тесты** — argparse, коды возврата, 40 модульных тестов.

## Требования

- Для готового `.exe`: Windows 10/11 x64, больше ничего.
- Для запуска из исходников: Python **3.8+** (проверено на 3.13 и 3.15), Windows / Linux / macOS.
- Сторонние пакеты **не нужны**; PyInstaller требуется только для сборки `.exe`.

## Готовый .exe для Windows

**Вариант 1 — скачать.** Откройте раздел **Releases** репозитория и скачайте
`rename_for_plex.exe` из последнего релиза. Python не нужен.

**Вариант 2 — собрать самому** (нужен Python 3.8+): см. [Сборка .exe](#сборка-exe).

Как пользоваться:

1. **Двойной клик** по `rename_for_plex.exe` → мастер спросит папку, режим просмотра и бэкап.
2. **Перетащить папку** с сериалом на значок `rename_for_plex.exe` — папка откроется сразу,
   останется ответить на вопросы.
3. **Из командной строки** — те же флаги, что у скрипта:

```bat
rename_for_plex.exe "D:\Serials" --dry-run
rename_for_plex.exe "D:\Serials" --backup --yes
```

Отличия exe от скрипта:

- окно **ждёт Enter** после работы, чтобы отчёт не исчез (отключается флагом `--no-pause`);
- `--version` и `--help` показывают `rename_for_plex.exe`;
- первый запуск может занять 1–2 секунды: один файл распаковывается во временную папку.

> ⚠️ **SmartScreen и антивирусы.** Файл собран PyInstaller и не подписан цифровой подписью, поэтому
> Windows может показать «Windows защитила ваш компьютер» → *Подробнее* → *Выполнить в любом случае*,
> а некоторые антивирусы — ложное срабатывание. Это нормально для неподписанных сборок; если не доверяете
> готовому файлу — соберите exe сами из исходников (одна команда) или запустите `rename_for_plex.py`.

## Командная строка

```bash
python rename_for_plex.py <папка> [флаги]
rename_for_plex.exe    <папка> [флаги]
```

| Флаг | Что делает |
| --- | --- |
| `<папка>` | Папка с видеофайлами. Если не указана — скрипт спросит её интерактивно. |
| `-n`, `--dry-run` | Только показать, что будет переименовано. Файлы не изменяются, бэкап не создаётся. |
| `-b`, `--backup` | Скопировать оригиналы в `_backup_<ГГГГММДД_ЧЧММСС>` перед переименованием. |
| `-y`, `--yes` | Не спрашивать подтверждение (для скриптов и планировщика). |
| `--no-recursive` | Не заходить во вложенные папки. |
| `--no-infer-series` | Не подставлять имя папки как название сериала. |
| `--no-pause` | Не ждать Enter в конце (обязательно для bat-файлов и планировщика). |
| `-V`, `--version` | Показать версию. |
| `-h`, `--help` | Показать справку. |

Примеры:

```bash
# Посмотреть план
python rename_for_plex.py "D:\Serials" --dry-run

# Переименовать с бэкапом и без вопросов
python rename_for_plex.py "D:\Serials" --backup --yes

# То же самое готовым exe
rename_for_plex.exe "D:\Serials" --backup --yes --no-pause

# Только текущая папка, без вложенных
python rename_for_plex.py "D:\Serials" --no-recursive

# На Linux/macOS
python3 rename_for_plex.py "/media/series" --dry-run
```

Коды возврата: `0` — успех, `1` — были ошибки переименования, `2` — папка не найдена, `130` — прервано пользователем.

## Как это работает

1. **Поиск маркера серии.** Регулярное выражение ищет `S01E01`, `S01.E01`, `S01EP01`, `1x01` или `Season 1 Episode 2`.
   Для формата `1x01` стоит защита от разрешений: `1920x1080` и `1280x720` серией не считаются.
2. **Название сериала** берётся из части имени до маркера: убираются скобки (`[RUS]`, `(1080p)`), год,
   релизные теги, точки и подчёркивания заменяются пробелами, `CamelCase` разбивается.
   Если названия нет — используется имя родительской папки.
3. **Название эпизода** берётся из части после маркера: отрезается всё начиная с первого релизного тега,
   убирается повтор названия сериала и лишняя пунктуация. Если осталось меньше 3 символов или только цифры —
   название не пишется.
4. **Сборка имени** и проверка на конфликты: занятое имя получает `(1)`, `(2)`; символы, недопустимые в Windows,
   удаляются; слишком длинное имя обрезается.
5. **Переименование** (или только вывод плана в `--dry-run`). Перед этим — резервная копия в `_backup_<дата>`,
   если запрошен `--backup`.

Список релизных тегов вынесен в константу `RELEASE_TAGS` в начале файла — его легко дополнить своей озвучкой
или релиз-группой, например `"myvoice"`.

## Безопасность

- `--dry-run` **ничего не меняет**: ни имена, ни файлы, ни папки. Бэкап в этом режиме не создаётся.
- `--backup` копирует оригиналы в `_backup_<дата>` с сохранением вложенности, и только потом переименовывает.
  Папки `_backup_*` никогда не сканируются и не переименовываются — в том числе при повторных запусках.
- Скрипт **не удаляет файлы** и не изменяет их содержимое: только `os.rename` и `shutil.copy2`.
- Конфликтов не будет: занятое имя получает суффикс `(1)`, `(2)` …, а переименование только за счёт регистра
  (`show - s01e01.mkv` → `Show - s01e01.mkv`) не создаёт лишнюю копию `(1)`.
- Ошибка на одном файле не останавливает обработку остальных — она попадает в счётчик «Ошибок».
- `--dry-run --backup` — бэкап не создаётся, режим просмотра имеет приоритет (скрипт об этом предупредит).

Проверить на копии данных, а не на единственном экземпляре, — всё равно хорошая идея.

## Сборка .exe

Сборка проверена на Windows x64, Python 3.13, PyInstaller 6.22.

**Самый простой способ** — двойной клик по `build_exe.bat`: он сам поставит PyInstaller (если нужно)
и соберёт файл.

**Вручную:**

```bash
python -m pip install -r requirements-dev.txt
python build_exe.py
```

Результат: `dist/rename_for_plex.exe` (~7 МБ, один файл, Python на целевой машине не нужен).

Параметры сборки:

```bash
python build_exe.py --onedir     # папка вместо одного файла — запускается быстрее
python build_exe.py --no-clean   # не очищать кэш сборки (повторная сборка быстрее)
python build_exe.py --name MyTool
```

Что делает `build_exe.py`:

- читает `__version__` из `rename_for_plex.py` и подставляет его в свойства файла
  (в Проводнике: *Свойства → Подробно* → «Версия файла», «Название продукта»);
- ставит иконку из `assets/icon.ico`;
- собирает `--onefile --console` в `dist/`, кэш и промежуточные файлы держит в `build/`.

Сборка в CI: workflow `.github/workflows/build-exe.yml` собирает exe на `windows-latest` при пуше тега `v*`
и прикрепляет его к GitHub Release. Достаточно:

```bash
git tag v2.1.0
git push origin v2.1.0
```

## Что исправлено в версии 2.0.0

Скрипт переписан после разбора ошибок исходной версии. Что было сломано и что изменилось:

| Проблема в исходной версии | Теперь |
| --- | --- |
| `Movie.2019.1920x1080.mkv` превращался в `Movie 2019 19 - s20e10`: разрешение `1920x1080` принималось за серию `20x10` | `1280x720` и `1920x1080` не считаются маркером серии; файл без серии пропускается |
| `Show.1080p.WEB-DL.S01E01...` → `Show 1080p WEB DL - s01e01`: мусор перед маркером оставался в названии | мусор до маркера отрезается, остаётся `Show - s01e01` |
| `Show.S01E01.Voyage.mkv` терял название серии: короткие теги (`vo`, `sub`, `ts`) резали слово `Voyage` | теги ищутся только как отдельные слова, `Voyage` сохраняется |
| Удаление дубля названия сериала резало строку по длине названия без пробелов: `Show Name Extra` → `e Extra` | дубль удаляется по словам, результат — `Extra` |
| Точки в названии эпизода оставались: `Some.Title` | `Some Title` |
| Папка `_backup_*` не исключалась из обхода: файлы внутри бэкапа могли быть переименованы повторно | список файлов собирается до создания бэкапа, `_backup_*` и скрытые папки не сканируются |
| Файлы `s01e01.mkv` без названия сериала пропускались | используется имя родительской папки |
| Переименование только за счёт регистра давало лишнее имя с `(1)` | регистр не считается конфликтом |
| Не было проверки недопустимых символов Windows, зарезервированных имён и длины | имена очищаются, `CON`/`COM1` получают префикс `_`, длинное имя обрезается |
| Эмодзи в консоли Windows (cp866) могли ронять скрипт; `input()` в конце вешал неинтерактивный запуск | UTF-8 включается безопасно, пауза только в интерактивном режиме, есть `--no-pause` |
| Мёртвый код (`strip_trailing_noise`, неиспользуемый `clean_episode_title`) | очистка названия эпизода вызывается из основного пути, дублирующие блоки удалены |
| Только интерактивный ввод | полноценный CLI (`--dry-run`, `--backup`, `--yes`, `--no-recursive`, `--no-infer-series`), коды возврата |

Полный список воспроизводимых случаев закреплён тестами в `tests/test_rename.py`.

## Ограничения

- Обрабатываются **только сериалы**. Фильмы (`Movie (2019).mkv`) считаются «не распознанными» и не переименовываются —
  так задумано, чтобы случайно не испортить кинотеку.
- Мультисерия (`S01E01E02`) получает имя только по **первой** серии: `s01e01`.
- Нет запросов к TMDB/IMDb: название берётся из имени файла как есть; регистр символов не нормализуется.
- Год (`YYYY`) добавляется только если он присутствовал в исходном имени.
- Разбиение CamelCase — эвристика: `iPhone` может стать `i Phone`.
- Не поддерживаются `E01` без сезона и абсолютная нумерация аниме.
- `.exe` собран для **Windows x64**; для ARM64 или 32-битной Windows пересоберите его на нужной платформе.
